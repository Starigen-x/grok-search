# 功能台账（老板的仪表盘）

> 状态流转：待办 → 进行中 → 待验收（老板亲手试）→ 完成；搁置 = 暂不做。
> 规则：全表同时只允许一个「进行中」；「待验收」攒到 3 个先请老板验收再开新活。
> 验收标准必须可机械核对；「老板怎么验证」必须是非程序员能照做的一步操作。
> **验收标准冻结**：某行验收标准经老板确认后，日常迭代只许改「状态」列；要动验收标准本身，必须在汇报中向老板点名说明（防悄悄改弱标准）。
