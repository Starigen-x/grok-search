# 架构与技术约束

> 维护人：技术合伙人。老板不需要读本文件。版本以 uv.lock 为准，本表只记选型与理由。

## 技术栈

| 层 | 选型 | 一句话理由 |
|---|---|---|
| 语言/运行时 | Python ≥3.11（uv 管理） | uvx 从 GitHub 地址直接安装是本产品的核心安装路径；uv 自动配 Python，不依赖系统版本 |
| MCP 框架 | FastMCP ≥3.2 | 当前主线版本，原生支持 stdio + Streamable HTTP 双形态与令牌鉴权（2026-08-17 经 Context7 核对 v3.2.4） |
| 上游调用 | httpx | 异步 HTTP 标准库，旧版已用，稳 |
| 网页提取 | trafilatura | 本地正文提取直出 Markdown，零密钥零外部依赖，替代 Tavily/Firecrawl |
| 重试 | tenacity | 带上限的指数退避 + Retry-After 支持，旧版逻辑经实战验证，移植保留 |
| 测试 | pytest + pytest-asyncio + respx | respx 模拟 httpx 上游，测试不打真实 API |
| 质检 | ruff（格式+lint）+ mypy（类型） | agent 友好：报错可读、单命令可跑 |

## 硬约束（动架构、加依赖前逐条核对）

- 依赖白名单制：新依赖必须在下表登记用途与理由；无理由不引入
- 黑名单：**禁止裸 `except Exception: pass/return None` 吞错**——旧版「来源永远为空」的病根就是它；任何失败必须向上冒出人话错误信息
- 密钥只从环境变量读取；禁止写入代码、日志、任何落盘文件；对外输出（含报错）必须脱敏
- 配置零落盘：不写 `~/.config`，不留第二处默认值——防「默认漂移」（老板规则文档记载过的真实事故）
- 重试必须有上限（次数 + 总时长）；禁无界循环
- 工具面收敛：对客户端暴露的工具数量是产品面，新增工具必须老板点头
- 所有工具返回结构里，错误一律走 `error` 字段或以「配置错误/网络错误/上游错误」开头的人话文本，客户端一眼可辨

## 决策记录（ADR-lite：只记「为什么」，防止日后翻案无据）

| # | 日期 | 决策 | 理由 | 被否的替代方案及原因 |
|---|---|---|---|---|
| 1 | 2026-08-17 | 沿用 Python，全新重写不做增量修补 | uvx git 安装路径依赖 Python 生态；老板已拍板一步到位 | TypeScript 重写：安装路径要换 npx，客户端配置更复杂，重写收益不抵 |
| 2 | 2026-08-17 | FastMCP 3.x | 当前主线，双形态 + 鉴权开箱即用 | 官方低层 mcp SDK：样板多；沿用 2.x：已非主线 |
| 3 | 2026-08-17 | 来源双路解析：优先上游 `citations` 字段，其次解析正文行内 `[[n]](url)` 引用；两路皆空时在返回中明示「本次无来源」 | 老板的代理网关不保证返回结构化引用字段；失败必须透明 | 只依赖 citations 字段：代理不返回就永远为空，重蹈旧版覆辙 |
| 4 | 2026-08-17 | web_fetch 用 trafilatura 本地提取 | 零密钥、零外部计费依赖，失败模式可控 | 继续 Tavily/Firecrawl：老板明确不想维护密钥；让 Grok 代读网页：不可靠且有幻觉风险 |
| 5 | 2026-08-17 | 配置只读环境变量，不落盘持久化 | 单一事实来源，根除「两处默认值漂移」事故 | 沿用 ~/.config/grok-search/config.json：正是漂移事故根源 |
| 6 | 2026-08-17 | ~~上游请求先用非流式 JSON~~ **修订：必须解析 SSE 流**——实测老板的网关无论是否请求流式，恒以 SSE 返回；解析时同步收集三路来源事件（行内引用、annotations 引用标注、search_sources 清单），普通 JSON 返回作为兼容后备 | 同日实测推翻原假设；三路来源事件正是旧版「来源永远为空」的解药 | 非流式：网关根本不提供 |
| 7 | 2026-08-17 | 工具面固定为 3 个：web_search / get_sources / web_fetch | 第三方客户端上下文宝贵；计划类、管理类工具实测无客户端会正确使用 | 保留 13 工具：臃肿、越权、拖慢客户端 |
| 8 | 2026-08-17 | HTTP 形态用静态 Bearer 令牌（env: GROK_HTTP_TOKEN） | 个人自用，静态令牌够用且零额外部件 | OAuth：为单用户场景引入整套授权服务，违反最少活动部件 |

## 目录结构约定

```
grok-search/
  src/grok_search/     # 全部源码：server.py(工具定义) config.py(环境变量) grok.py(上游客户端)
                       #           sources.py(来源解析+会话缓存) fetch.py(网页提取)
  tests/               # pytest 测试，与源码模块一一对应
  docs/                # PRD、架构、台账、手册、技术债
  Makefile             # 质量门与常用命令入口（make check / make serve）
  pyproject.toml       # 项目定义 + 依赖 + 工具配置；uvx 安装入口
```

## 环境变量清单（客户端配置的全部内容）

| 变量 | 必填 | 说明 |
|---|---|---|
| GROK_API_URL | 是 | 上游搜索 API 地址（OpenAI 兼容格式） |
| GROK_API_KEY | 是 | 上游 API 密钥 |
| GROK_MODEL | 是 | 模型名（如 grok-4.3-fast） |
| GROK_HTTP_TOKEN | HTTP 形态必填 | 网络服务模式的访问令牌，防陌生人盗用 |
| GROK_TIMEOUT_S | 否 | 上游读超时秒数，默认 120 |
| GROK_DEBUG | 否 | 调试日志开关，默认关 |
